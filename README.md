# Moduler-packager

A short Python program that combines daily utilities, math tools, and file helpers into one simple terminal menu.

## Core Features
* **Time Tools:** Check current time, format dates, or use the countdown timer.
* **Math Helpers:** Calculate factorials, square roots, and angles instantly.
* **Developer Tools:** Generate random values, secure UUIDs, and view module lists.

## Python Concepts Used
* Modules & Imports (`math`, `datetime`, `uuid`)
* Menu Loops & Conditional Logic
* User Input Validation
* Exception & Error Handling
